# 饮食热量记录站 🥗

蓝色手账风 · 个人饮食热量记录网站。纯原生 HTML / CSS / JS，无框架，数据存 localStorage。

## 页面模块（单页 Tab 切换）

| Tab | 状态 | 说明 |
| --- | --- | --- |
| 🍜 食物库 | ✅ 已完成 | 100 款食物卡片（含三大营养素 + 手账标签）、搜索、筛选（7 分类）、排序、收藏 |
| 🧮 热量计算器 | ✅ 已完成 | 份数/克数切换、合计、三级评估、保存到今日记录 |
| 📖 饮食记录 | ✅ 已完成 | 日期分组（今天/昨天/更早）+ 餐次分类、编辑/删除、当日合计、近 7 天 CSS 柱状图 |
| 💬 关于 | ✅ 已完成 | 使用说明 + 计量方式 + 隐私说明 + 免责声明 + 清除本地数据 |

## 本地预览

```bash
# 方式一：直接双击 index.html 打开
# 方式二：起一个本地静态服务（更稳定）
cd D:\AI_use\YinShi
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 修改指南

- **改食物数据**：编辑 `js/data.js`，在 `FOODS` 数组增删对象。每个对象含名称、emoji、分类、计量方式（`measure: count/weight`）、热量 `cal`、三大营养素 `p/c/f`、标签 `tags`、营养要点与减脂提示（字段说明见文件顶部注释）。
- **改配色**：编辑 `css/style.css` 顶部的 `:root` 变量。
- **改文案 / 免责声明**：编辑 `index.html`。

## 数据说明

所有热量数据均为估算值，仅供个人减脂参考，不构成医疗建议。
