# 饮食热量记录站 🥗

蓝色手账风 · 个人饮食热量记录网站。纯原生 HTML / CSS / JS，无框架，数据存 localStorage。

## 升级路线（一次一个模块，做完确认再继续）

1. ✅ **全局设计系统 + 导航 + 数据结构**
   - 设计系统常量集中在 `js/data.js`：`UNIT_INFO`（单位换算表）、`SPICY_LEVELS`（辣度）、`CUISINE_LIB`（八大菜系登记）、`NUTRI_GROUPS`（高蛋白/高纤维/低GI/高钙/高铁/维C/钾/低脂/低糖）
   - localStorage 加版本前缀 `ys.v3.*`，旧数据自动无损迁移；`esc()` XSS 转义
   - 术语统一：热量单位一律 `kcal（千卡）`；「减脂人最爱」→「低卡优选」
   - 食物卡片新增可选字段：`science`（科普短句）、`grams`（单份估算克重）、`spicy`（辣度）等
2. ✅ **食物库升级**：🧬 营养素分类筛选（`NUTRI_GROUPS`，可多选叠加）、🔍 搜索历史（去重置顶，最多 8 条）+ 热门搜索面板、📖 统一食物详情模板（食物库/菜系/品牌共用）
3. ✅ **热量计算器升级**：单行估算三大营养素 + 克重标注、一餐三类营养素合计卡、校验文案统一「份数/克重必须大于 0。」
4. ✅ **饮食记录升级**：✏️ 编辑餐次/日期、导出 📄 JSON / 📊 CSV（UTF-8 BOM + 防公式注入 + 含估算营养素）
5. ✅ **八大菜系 + 全国风味（4 批）**：`foods-cn-1.js` 八大菜系代表菜 64 道（每系 8 道，id 101+）；`foods-cn-2.js` 华北 5 省 60 道（id 165+）；`foods-cn-3.js` 东北+华东 10 省 60 道（id 225+）；`foods-cn-4.js` 华中+华南 6 省 60 道（id 285+，河南/湖北/湖南/广东/广西/海南 各 10 道）；各批次末尾 `CN_FOODS.push()` 合并进全国主库；菜系页支持「八大菜系 / 全国风味」模式切换、菜系小百科、省区筛选、搜索/排序；`getFood` 贯通全库；其余省份（西南/西北）分批续更
6. ⏳ 品牌热量库
7. ⏳ 运动消耗与动作指导模块

## 修改指南

- **改食物数据**：编辑 `js/data.js`，在 `FOODS` 数组增删对象。每个对象含名称、emoji、分类、计量方式（`measure: count/weight`）、热量 `cal`、三大营养素 `p/c/f`、标签 `tags`、营养要点与减脂提示（完整字段说明见文件顶部注释）。
- **改设计系统常量**：`js/data.js` 中部的 `UNIT_INFO / SPICY_LEVELS / CUISINE_LIB / NUTRI_GROUPS`。
- **改配色**：编辑 `css/style.css` 顶部的 `:root` 变量。
- **改文案 / 免责声明**：编辑 `index.html`。
- **localStorage 结构升级**：修改 `LS_KEYS` 版本号（如 `ys.v4.*`），旧数据由 `migrateLegacyLS()` 自动迁移。

## 数据说明

所有热量数据均为估算值，仅供个人减脂参考，不构成医疗建议；品牌数据以官方小程序 / 包装为准。
